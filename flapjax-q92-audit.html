Reading of the funder evidence. A recipient with nonce = 0 and balance = 0 BNB has never been the destination of a native BNB transfer on BSC. Its gas for the FLAPJAX claim must therefore have been paid by a relayer or the token contract itself, and no first-funder link can be established from the chain. Ten of the eleven recipients fall in this class, so the funder analysis supports 10 distinct outside operators plus one Treasury-seeded group — 11 groups total.
Boundary of the claim. "No identifiable first funder" is a statement about what the chain shows, not proof that ten separate humans exist. A single operator can hold ten never-funded wallets and claim from each. The funder grouping is an upper bound on operator count only in the weak sense that it cannot link them; it cannot separate them either. Anything stronger would need off-chain identity evidence, which this audit does not use.

7. Method

  • Source of truth: public BSC JSON-RPC (https://bsc-dataseed.bnbchain.org). No explorer API, no third-party index.
  • Per-transfer check: eth_getTransactionReceipt for each tx, asserting status == 0x1, blockNumber matches, and exactly one FLAPJAX Transfer log with from == treasury, to == claimed recipient, and value == claimed amount × 10^18.
  • Boundary blocks: eth_getBlockByNumber timestamps read directly, so the day window is anchored to chain time rather than wall-clock.
  • Funder state: eth_getTransactionCount and eth_getBalance at latest block for every recipient.
  • Linking tx: eth_getTransactionReceipt plus the block's transaction list to recover from, to and value for the treasury → 0xfb200657… BNB transfer.
Tooling limits, stated plainly. Public BSC nodes rate-limit or refuse eth_getLogs with block-range filters, and the dataseed is not an archive node (eth_call at historical blocks returns missing trie node). This audit therefore verifies transfers receipt by receipt rather than by a single log sweep. That is sufficient to confirm every claimed transfer and to confirm the totals, but it cannot by itself prove that no transfer was omitted — an omission would need a full log sweep to detect. Any reader who can run eth_getLogs against an archive node is invited to close that gap.
